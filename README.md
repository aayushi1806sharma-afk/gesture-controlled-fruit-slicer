# Gesture-Controlled Fruit Slicer 🍎🎮

A real-time gesture-controlled Fruit Ninja style game built using **Python, OpenCV, MediaPipe, and Pygame**.  
The project uses webcam-based hand tracking to let users slice fruits using finger gestures without touching the keyboard or mouse.

---

## 🚀 Features

- ✋ Real-time hand tracking using MediaPipe
- 🍎 Gesture-based fruit slicing mechanics
- 💣 Bomb detection and game over system
- ✨ Particle explosion effects
- ⚡ Combo-based scoring system
- 🗡️ Dynamic sword trail effect
- 🔊 Sound effects integration using Pygame
- 🎮 Start menu and retry system
- 📷 Smooth webcam-based gameplay

## 🎮 How to Play

- Move your hand in front of the webcam
- Use your index finger as a virtual blade
- Slice fruits to increase your score
- Avoid bombs to survive
- Build combos for higher points
