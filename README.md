Gesture-Controlled Fruit Slicer 🍎🎮

A gesture-controlled Fruit Ninja style game built using Python, OpenCV, MediaPipe, and Pygame. The project uses real-time hand tracking to allow users to slice fruits using finger gestures captured through a webcam.

🚀 Features
Real-time hand tracking using MediaPipe
Gesture-based fruit slicing mechanics
Dynamic fruit and bomb spawning system
Combo-based scoring system
Interactive sword trail effect
Particle explosion effects
Sound effects integration using Pygame
Start menu and retry system
Smooth real-time gameplay using OpenCV
🛠️ Tech Stack
Python
OpenCV
MediaPipe
NumPy
Pygame

▶️ Installation

Clone the repository:

git clone https://github.com/YOUR_USERNAME/gesture-controlled-fruit-slicer.git

Install dependencies:

pip install -r requirements.txt

Run the project:

py -3.11 main.py
🎮 Controls
Move your hand in front of the webcam
Use your index finger as a virtual blade
Slice fruits to increase score
Avoid bombs to survive
